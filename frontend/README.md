# Frontend

React frontend for the Inventory & Order Management System.

## Scripts

```bash
npm run dev
npm run lint
npm run build
npm run preview
```

## Mock API Mode

Mock mode is enabled unless `VITE_USE_MOCK_API=false`.

```bash
VITE_API_BASE_URL=http://localhost:8000
VITE_USE_MOCK_API=true
```
